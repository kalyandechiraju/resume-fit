Resume Fit v0.3.1 fixes release and startup issues found during the open-source review.

## Changes

- Prevented the side panel from missing captures that arrive during startup.
- Added third-party license notices to the extension ZIP.
- Added GitHub Actions checks and a security policy.
- Removed unused report data and corrected the architecture documentation.
- Added failure handling to panel and service-worker operations.

## Install

1. Download `resume-fit-v0.3.1.zip` below.
2. Unzip the file.
3. Open `chrome://extensions`.
4. Turn on **Developer mode**.
5. Select **Load unpacked** and choose the unzipped folder.

Chrome 116 or later is required. A Vercel AI Gateway API key is required to run an analysis.
