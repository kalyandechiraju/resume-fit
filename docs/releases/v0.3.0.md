Resume Fit is ready for manual installation in Chrome.

## What is included

- PDF and DOCX resume parsing on the user's device
- Job-description capture from the current Chrome tab, with paste fallback
- Resume-to-job evaluation through Vercel AI Gateway and TypeSafe Jev
- A compact results screen with an overall semicircle score and horizontal metric bars
- Session-only storage for the API key and current job

## Install

1. Download `resume-fit-v0.3.0.zip` below.
2. Unzip it.
3. Open `chrome://extensions`.
4. Turn on **Developer mode**.
5. Select **Load unpacked** and choose the unzipped folder.

Chrome 116 or later is required. You also need a Vercel AI Gateway API key to run an analysis.

See the [README](https://github.com/kalyandechiraju/resume-fit#readme) for setup, usage, privacy, and source-build instructions.
